# CodeGram 14.5.0 / служба VPS 5.3.0

## Современный интерфейс без Liquid Glass

Современная компоновка Telegram сохранена: расположение, размеры, формы и скругления
выбираются современными компонентами. Политики ClassicDesign и GlassEffects разделены:
ClassicDesign принудительно выключен, оптический материал, линзы, рефракция и стеклянные
переходы отключены. Вместо стекла используются плоские поверхности приложения.
Системные окна за пределами приложения остаются под управлением iOS.

Настройки CodeGram собраны в общие группы с внутренними разделителями и внешними
скруглениями. Выбор иконки использует реальную высоту экрана: предпросмотр по центру,
кнопка установки у нижнего края. Для девяти вариантов добавлены разные короткие эффекты.
Они заканчиваются примерно за 1,3 секунды, заменяются при быстром переключении и
останавливаются в фоне, при Reduce Motion и энергосбережении.

## Отправка видео без блокирующего окна

Поддерживаемая ссылка создаёт задание, привязанное к исходным аккаунту, чату, теме,
ответу, отправителю и параметрам отправки. Поле очищается в момент принятия задания;
последующие сетевые ответы не меняют новый черновик. Можно писать дальше и переходить
в другие чаты. Локальная плашка показывает подготовку и позволяет отменить или повторить
задание. Получателю отправляется видео через обычную очередь Telegram.
Подтверждение платных сообщений и выбор времени отправки сохраняются.

На аккаунт допускается до восьми активных заданий. Если очередь заполнена, ссылка
остаётся в поле, а закрываемое уведомление исчезает через восемь секунд. Оно появляется
и тогда, когда все задания относятся к другим чатам.

Одинаковые ссылки разделяют подготовку, но каждое явное нажатие «Отправить» остаётся
отдельным сообщением. Готовые файлы кешируются на телефоне с ограничениями по сроку,
количеству и объёму. После загрузки в Telegram доступная облачная ссылка запоминается
в памяти текущей сессии аккаунта: повторная отправка может обойтись без повторного
скачивания и загрузки. В секретных чатах используется обычная загрузка файла.

Подготовка живёт в процессе приложения. iOS предоставляет ограниченное фоновое время;
продолжение после принудительного закрытия или завершения процесса не гарантируется.
После передачи сообщения обычная очередь Telegram управляет его загрузкой и повторами.

На VPS готовые результаты переживают перезапуск службы. Поддерживаются нормализованные
ссылки и TikTok ID, ограниченная параллельная обработка и объединение одинаковых запросов.
Совместимый H.264/AAC MP4 с faststart не обрабатывается повторно без необходимости.
Скорость первой отправки зависит от доступности источника, размера ролика и сети.

## TikTok

Добавлен браузерный транспорт yt-dlp/curl_cffi для публичных страниц TikTok. Он проверяет
TLS и публичные DNS-адреса, фиксирует проверенный адрес подключения, проверяет каждый
переход и удаляет чувствительные заголовки при смене узла. Непроверенные автоматические
перенаправления и исходный транспорт с отдельным DNS-разрешением отключены.
Закрытые ролики, вход в аккаунт и ограничения доступа не обходятся.

Настоящий TikTok extractor проверен на локальном сетевом fixture с подменённой curl Session.
Это подтверждает маршрутизацию и разбор ответа, но не загрузку конкретного ролика через
IP владельца VPS. При ошибке локальная запись сохраняет ссылку и безопасную диагностику
с версией службы и этапом сбоя.

## Сигналы возможной блокировки и история

Telegram не сообщает заблокированному пользователю о входящей блокировке.
`userFull.blocked` означает собственную блокировку собеседника. Статус «был давно»,
отсутствующее фото и видимость подарков не позволяют установить чужой ЧС со стопроцентной
уверенностью.

Возможное ограничение отмечается только после совместной потери ранее доступных статуса
и фото в пределах свежего, двухминутного окна наблюдений. Первоначально отсутствующие
данные, скрытые подарки, одиночный offline-сигнал, удаление аккаунта и собственный ЧС
не создают событие возможной блокировки. Восстановленная видимость тоже не называется
подтверждённой разблокировкой; `blocked_by_target` остаётся неизвестным. Собственные
действия в чёрном списке записываются отдельно как подтверждённые.

Семантика блокировок: [официальное описание Telegram](https://core.telegram.org/api/block)
и [userFull](https://core.telegram.org/constructor/userFull).

Полученные события `UpdateUserStatus` обрабатываются сразу. Полная проверка профиля
имеет базовый интервал 15 секунд; очередь, сеть и лимиты Telegram увеличивают задержку.
Получение каждого события и восстановление сторис, удалённой до получения её данных
и файла, не гарантируются.

Открытая история и выбранная запись автоматически получают изменения с VPS.
При новых событиях сохраняется место чтения; смена архива сбрасывает старую пагинацию,
не смешивая записи разных баз.

## Обновление службы VPS

Закреплён серверный код `2b7ad4a0c89855165e0c7a289e091bf4b8e35a68`.
Вставить под root одну строку целиком. Для другого домена заменить `archive.mavasyaa.best`.
`--reuse-session` сохраняет существующие настройки, Telegram-сессию и базу архива.

~~~bash
apt-get update && apt-get install -y git ca-certificates && cg_dir=$(mktemp -d /tmp/codegram-v5.3.XXXXXX) && git clone --depth 1 --filter=blob:none --sparse --branch codex/codegram-14.4-links-profile-icons https://github.com/vaysenko7882/Nikita-iOS.git "$cg_dir" && git -C "$cg_dir" fetch --depth 1 origin 2b7ad4a0c89855165e0c7a289e091bf4b8e35a68 && git -C "$cg_dir" checkout --detach FETCH_HEAD && git -C "$cg_dir" sparse-checkout set server && bash "$cg_dir/server/install.sh" --domain archive.mavasyaa.best --reuse-session && /opt/nikita-archive/venv/bin/pip show nikita-archive && systemctl is-active nikita-archive
~~~

Если терминал показывает `>`, сначала нажать Ctrl+C. Ожидаемый результат — `Version: 5.3.0` и `active`.
Команда подготовлена и проверена по исходникам; на VPS владельца она не запускалась.
