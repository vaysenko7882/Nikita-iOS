# Никита

Личный неофициальный Telegram-клиент для iPhone на базе открытого MadGram.

**Версия 13.1.3 (8) успешно скомпилирована для iPhone.**
[Сборка и IPA](https://github.com/vaysenko7882/Nikita-iOS/actions/runs/41174955100).
IPA нужно подписать собственным сертификатом.

Белая N на синем фоне и плашка НИКИТА, полупрозрачные удалённые сообщения, сохранение ссылок на версии правок,
запрос дополнительного фонового времени, интеграция с личным VPS и VoiceChanger для голосовых.

Исправлен вылет после подключения VPS: состояние синхронизации сохраняется в формате, поддерживаемом Postbox.
Старые настройки мигрируют без чтения проблемного словаря; локальный архив сохраняется.
Проверки старого/нового формата и повторного запуска прошли на настоящем кодеке Postbox.

[Настройка VPS с iPhone](server/README.md) · [Возможности, ограничения и сборка](NIKITA.md)

Сервер сохраняет только полученные текст, подписи и сведения о вложениях; сами медиа с VPS не скачиваются.
iOS не гарантирует пять минут работы после сворачивания.
Запуск на устройстве, визуальная проверка и подключение реального VPS ещё не выполнены.

Сохранены авторство и лицензии [MadGram](https://github.com/yar2slav/Madgram-iOS) и [Telegram iOS](https://github.com/TelegramMessenger/Telegram-iOS).
Клиент не связан с Telegram и не одобрен им.
