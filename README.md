# Autismex 2.3 — iOS

Нативное приложение на SwiftUI для панели присутствия `https://autismex.best`.
Читает тот же API, что и сайт: `/api/state`, `/api/events` (SSE), `/api/diagnostics`,
`/api/export.csv`, `/api/avatar`. Сервер менять не нужно.

## Что нового в 2.3

- **Новая иконка**: сам циферблат приложения — кольцо сеансов, внутри точки привычных часов, в центре точка присутствия. Композиция строго по центру.
- **Порядок экрана от близкого к далёкому**: сейчас → выбранный день (циферблат, плитки, хроника) → неделя → месяц → всё время.
- **«Показать на циферблате»**: нажатие на сообщение в хронике или на плитку со значком прицела прокручивает к циферблату и наводит стрелку на этот отрезок.
- **Плашка статуса вверху**: когда карточка статуса прокручена, сверху остаётся маленькая плашка «В сети 3 мин 44 с». Нажатие возвращает к началу. Работает на iOS 18 и новее.
- **Панель дня отвечает сразу**: подпись меняется в момент нажатия, стрелку можно нажать несколько раз подряд.
- **Сравнение с обычным днём** вместо сравнения со вчера: «На 12 мин больше обычного к этому часу».
- **Четыре одинаковые плитки**: сеансы, паузы, первый выход, долгий сеанс.
- **В «Ритме недели»** открытый день подсвечен полосой.

## Экраны

- **Статус**: аватар с кольцом, крупно «В сети» или «Офлайн», под ним длительность и время начала. Меню «⋯»: поделиться днём, экспорт CSV, сайт, связь с Telegram, обновить.
- **Циферблат суток**: удерживай кольцо и веди пальцем — в центре время отрезка, на каждом новом отрезке лёгкий щелчок. Короткое касание показывает отрезок под пальцем.
- **Плитки**: сеансы, паузы, первый выход, долгий сеанс.
- **Хроника**: сеансы как исходящие сообщения, паузы как служебные плашки.
- **Ритм недели**: точки по часам, пиковый час и среднее за день. Касание точки показывает минуты, касание дня открывает его.
- **День за днём** с чертой среднего, итоги за всё время, связь с Telegram.
- **Панель дня** внизу: стрелки, календарь, «Сегодня». Смахивание по панели листает дни.
- **Виджеты**: маленький и средний на домашний экран; круглый, прямоугольный и строчный на экран блокировки.

## Сборка

Нужен Xcode 16 или новее (проект использует синхронизированные папки, objectVersion 77).
Минимальная iOS — 17.0.

**Неподписанный IPA:**

```bash
./scripts/build-unsigned-ipa.sh
```

Файл `Autismex-unsigned.ipa` появится в корне. Подписывай его как раньше: Sideloadly, AltStore, TrollStore или своим сертификатом.

**Через GitHub Actions:** положи папку в репозиторий. Workflow `.github/workflows/build-ipa.yml` соберёт IPA и прикрепит его к запуску как артефакт.

**Прямо на телефон из Xcode:** открой `Autismex.xcodeproj`. В Signing & Capabilities у целей `Autismex` и `AutismexWidgetExtension` выбери свою команду и нажми Run.

## Настройки

- Адрес сервера: `Shared/PresenceAPI.swift`, константа `defaultBase`.
- Bundle ID: `best.autismex.presence` у приложения и `best.autismex.presence.widget` у виджета. Если бесплатный аккаунт Apple ругается на лимит идентификаторов, поменяй оба на свои; ID виджета должен начинаться с ID приложения.

## Структура

```
Autismex/          приложение: экраны, жесты, стор (Observation) с SSE и опросом
AutismexWidget/    виджеты WidgetKit
Shared/            модели API, форматирование, палитра, отрисовка циферблата (общие для обеих целей)
```
