# Autismex 2.0 — iOS

Нативное приложение на SwiftUI для панели присутствия `https://autismex.best`.
Читает тот же API, что и сайт: `/api/state`, `/api/events` (SSE), `/api/diagnostics`,
`/api/export.csv`, `/api/avatar`. Сервер менять не нужно.

## Что внутри

- **Живая карточка статуса.** Аватар с кольцом: зелёное — в сети, пунктирное — статус неизвестен. Таймер идёт каждую секунду. Карточка становится мятной, пока аккаунт онлайн.
- **Циферблат суток.** Полночь сверху, сеансы онлайн — зелёные дуги. Удерживай кольцо и веди пальцем: в центре видно время отрезка, на каждом новом отрезке телефон отвечает лёгким щелчком. Короткое касание показывает отрезок под пальцем. При смене дня кольцо прорисовывается по часовой стрелке.
- **Сравнение со вчера** в то же время суток, первый и последний выход в сеть, самый долгий сеанс.
- **Ритм недели** — точечная карта по часам, пиковый час и среднее за день.
- **Хроника дня** в виде переписки: сеансы — исходящие сообщения, паузы — служебные плашки, текущий сеанс «печатает…».
- **День за днём** с чертой среднего, итоги за всё время, диагностика связи с копированием.
- **Панель дня внизу экрана**: стрелки, календарь, кнопка «Сегодня». Смахивание по панели листает дни.
- **Виджеты**: маленький и средний на домашний экран, круглый, прямоугольный и строчный на экран блокировки.
- Светлая и тёмная тема. Настройка «Уменьшение движения» отключает анимации.

## Сборка

Нужен Xcode 16 или новее (проект использует синхронизированные папки, objectVersion 77).
Минимальная iOS — 17.0.

**Неподписанный IPA, как прежний файл:**

```bash
./scripts/build-unsigned-ipa.sh
```

Файл `Autismex-unsigned.ipa` появится в корне. Подписывай его как раньше: Sideloadly, AltStore, TrollStore или своим сертификатом.

**Через GitHub Actions:** положи папку в репозиторий. Workflow `.github/workflows/build-ipa.yml` соберёт IPA и прикрепит его к запуску как артефакт.

**Прямо на телефон из Xcode:** открой `Autismex.xcodeproj`. В Signing & Capabilities у целей `Autismex` и `AutismexWidgetExtension` выбери свою команду и нажми Run.

## Настройки

- Адрес сервера: `Shared/PresenceAPI.swift`, константа `defaultBase`.
- Bundle ID: `best.autismex.presence` у приложения и `best.autismex.presence.widget` у виджета. Если бесплатный аккаунт Apple ругается на лимит идентификаторов, поменяй оба на свои; ID виджета должен начинаться с ID приложения.

## Структура

```
Autismex/          приложение: экраны, жесты, стор с SSE и опросом
AutismexWidget/    виджеты WidgetKit
Shared/            модели API, форматирование, палитра, отрисовка циферблата (общие для обеих целей)
```
