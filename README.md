# Никита

Персональный неофициальный Telegram-клиент для iPhone на базе открытого MadGram.

В этой ветке изменены название и иконка приложения, добавлены быстрые настройки режима призрака и постоянного архива, включено хранение архива между перезапусками для новых установок.

**Статус: изменения исходников подготовлены; iOS-сборка и проверка на устройстве не выполнены.**

Облачный сценарий находится в `.github/workflows/build.yml`. Для запуска нужны доступ к вашему GitHub и собственные Telegram API ID / API hash в secrets репозитория. Сертификат iPhone для облачной сборки не передаётся.

Подробности, ограничения и порядок сборки: [NIKITA.md](NIKITA.md).

База: [MadGram v1.0.18](https://github.com/yar2slav/Madgram-iOS/tree/v1.0.18), commit `864cac9c27025ef6420187e12f6a4c3ce39fc4af`, производный проект [Telegram iOS](https://github.com/TelegramMessenger/Telegram-iOS).

Сохранены upstream-исходники, авторство и применимые лицензии. Собственные изменения не означают авторство исходного Telegram или функций MadGram. Клиент не связан с Telegram и не одобрен им.
