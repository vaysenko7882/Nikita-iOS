# CodeGram 14.4.1 / сервер 5.1.0

Исправления отслеживания профилей и подготовки публичных видео. Протокол VPS остаётся версии 5;
обновляются и приложение iPhone, и установленная серверная служба. Прежние ключ, сессия и архив сохраняются.

## Сторис и изменения профиля

Полученные события имени, статуса и аватарки записываются без ожидания очередной полной проверки профиля.
Событие удаления сторис теперь сохраняется отдельно. Если Telegram прислал только сокращённое описание,
оно сразу попадает в журнал, а полное содержимое запрашивается отдельно. Отсутствие загруженного файла
не маскируется под сохранённую фотографию или видео.

Загрузке файлов сторис выделен отдельный работник: большие вложения архива не занимают его очередь.
Новая задача будит ожидающий загрузчик сразу. Уже сохранённые файлы и журнал не удаляются.
Открытая первая страница истории на iPhone обновляется каждые пять секунд; просмотр старых страниц,
прокрутка и уход приложения в фон приостанавливают автоматическое обновление.

Резервная проверка профиля выполняется от 15 секунд, подарков — от 60 секунд и раньше при изменении
доступного счётчика подарков. Это интервалы между проверками, а не обещанная задержка каждого события:
профили обслуживаются общей очередью с ограничением частоты запросов и паузами FLOOD_WAIT.

Telegram присылает события сторис подписчикам/контактам с учётом доступности истории. Для произвольного
пользователя событие может не прийти. Историю, опубликованную и удалённую между проверками без доставленного
события, восстановить нельзя. Даже при полученном событии байты могут стать недоступны до скачивания.
Гарантии «абсолютно всё за две секунды» нет.

Telegram не отправляет вашему аккаунту уведомление о том, что другой человек заблокировал или разблокировал
вас. Изменение видимости фото или статуса может быть связано с приватностью. Такие изменения записываются
как изменения доступности; ваш собственный список блокировок учитывается отдельно.

Первичные источники: [блокировки](https://core.telegram.org/api/block),
[события сторис](https://core.telegram.org/api/stories).

## Reels и TikTok

Расширена обработка распространённых ссылок «Поделиться» и доступных MP4-потоков. Поддерживается объединение
раздельных потоков видео и звука без перекодирования видео. Сохраняются ограничения на публичные HTTPS-источники,
один ролик, размер 250 МБ и ограниченную очередь работ.

Клиент показывает причину сбоя: источник требует входа, ограничил запросы, не отвечает, предоставил неподходящий
кодек; либо на VPS не хватает места/компонентов или не удалось подготовить MP4. Сбой передачи файла с VPS
на iPhone отличается от сбоя получения видео от сайта. При отказе или отмене черновик сохраняется.
Работоспособность конкретного ролика зависит от ответа сайта с IP VPS; приватные аккаунты и cookies не добавлялись.

## Обновление

На уже установленном VPS под root вставить целиком одну строку. При другом домене заменить
`archive.mavasyaa.best` своим доменом. Команда проверяет версию исходников перед запуском установщика:

```bash
apt-get update && apt-get install -y git ca-certificates && codegram_update_dir=$(mktemp -d /tmp/codegram-v5.1.XXXXXX) && git clone --depth 1 --filter=blob:none --sparse --branch codex/codegram-14.4-links-profile-icons https://github.com/vaysenko7882/Nikita-iOS.git "$codegram_update_dir" && git -C "$codegram_update_dir" sparse-checkout set server && grep -q '^version = "5.1.0"$' "$codegram_update_dir/server/pyproject.toml" && bash "$codegram_update_dir/server/install.sh" --domain archive.mavasyaa.best --reuse-session && /opt/nikita-archive/venv/bin/pip show nikita-archive && systemctl is-active nikita-archive
```

Повторная проверка установленного пакета:

```bash
/opt/nikita-archive/venv/bin/pip show nikita-archive
systemctl is-active nikita-archive
```

Ожидаются `Version: 5.1.0` и `active`. На iPhone установить новую IPA поверх прежней с тем же bundle ID
`personal.nikita.messenger` и прежней подписью. Не удалять приложение перед обновлением.

## Проверка

Регрессионные тесты покрывают быстрые события публикации/удаления, сокращённые сторис, частичные обновления
полей, отдельную очередь файлов сторис, ссылки и классификацию ошибок видео. Медиатесты используют настоящие
yt-dlp/ffprobe/ffmpeg с контролируемыми файлами. Авторизованный поток Telegram, конкретные публичные ролики
с IP владельца и подписанная установка на физическом iPhone требуют отдельной проверки.
