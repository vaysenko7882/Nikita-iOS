# CodeGram 14.4

Актуальные исправления: [CodeGram 14.4.1 и сервер 5.1.0](CODEGRAM-14.4.1.md).
Ниже сохранены описание и проверенная сборка первоначального выпуска 14.4.0.

## Видео вместо ссылки

CodeGram → Сообщения → «TikTok и Instagram → видео». Выключатель по умолчанию отключён.
Одна HTTPS-ссылка на публичный ролик TikTok или видеопост/Reel Instagram подготавливается на собственном VPS,
скачивается на iPhone потоком во временный файл и отправляется обычным механизмом Telegram как видео.
Ограничение — 250 МБ и один ролик за отправку. Дополнительный текст, несколько ссылок, правки и пересылки
сохраняют обычное поведение. При ошибке и отмене черновик сохраняется. Изменённый во время подготовки
черновик или ответ на сообщение не отправляется старым запросом.

Нужен сервер версии 5. Закрытые ролики, вход в Instagram/TikTok и cookies не поддерживаются.
Работа зависит от доступности ролика с IP VPS. yt-dlp работает в отдельном ограниченном процессе;
MP4/H.264 переупаковывается без перекодирования видео. Временные результаты ограничены очередью и очищаются
при новых запросах после часа хранения либо при перезапуске службы. Существующий архив не удаляется.

## История профиля

В профиле человека → «Отслеживание профиля». Общий список находится в CodeGram → Дополнительно.
Только явно включённые пользователи наблюдаются с имеющейся Telegram-сессии VPS, в том числе при закрытом iPhone.
Доступные события изменения имени и профиля, а также полные события сторис записываются после получения.
Плановые проверки профиля и доступных сторис идут очередью от 30 секунд, подарков — от пяти минут.
Запросы профилей выполняются последовательно с интервалом не менее секунды; при FLOOD_WAIT соблюдается пауза.
Частота зависит от количества профилей и ограничений Telegram. Максимум — 50 включённых профилей.

Журнал содержит прежние и новые имена, юзернеймы, описание, оформление, доступные дополнительные поля,
главную и доступные аватарки, видимые подарки и их атрибуты/отправителя/дату, порядок витрины и доступные сторис.
Данные и файлы хранятся на VPS. iPhone загружает страницы истории по запросу и файлы при открытии.
Отключение наблюдения сохраняет историю. Неполная или неудачная загрузка коллекции не считается удалением подарков.

Telegram не раскрывает достоверный статус «этот человек заблокировал меня». Журнал доступности показывает
полученные изменения фото, описания и видимости статуса, без утверждений о ЧС. Флаг «заблокирован мной»
отделён от неизвестного статуса блокировки другой стороной. Скрытого отправителя подарка, недоступную сторис
и изменения, которые Telegram не прислал и которые исчезли между проверками, восстановить нельзя.
Дата в списке событий — время обнаружения на VPS; исходные даты Telegram находятся в данных события.

## Иконки

CodeGram → Оформление → «Иконка приложения». Карусель использует исходный значок и восемь изображений владельца.
Прокрутка меняет предпросмотр и фон; применение происходит только по кнопке через публичный системный API iOS.
Изображения не перерисовываются. Генератор создаёт PNG для iPhone/iPad и компактные предпросмотры.
Значки строк настроек Telegram обрезаются по кругу; их цвета и рисунки сохраняются.

## Обновление VPS

Под root на уже установленном VPS выполнить весь блок. Он загружает проверенные исходники
`55cb132946763880dc14561edb95e0a3c654cadf` во временную папку, затем обновляет сервер до версии 5
с прежними конфигурацией, Telegram-сессией, ключом и базой. Установщик добавляет ffmpeg и зависимости.

```bash
bash <<'CODEGRAM_UPDATE'
set -euo pipefail
export DEBIAN_FRONTEND=noninteractive NEEDRESTART_MODE=l
apt-get update
apt-get install -y git ca-certificates
codegram_update_dir=$(mktemp -d /tmp/codegram-14.4.XXXXXX)
git clone --depth 1 --filter=blob:none --sparse --branch codex/codegram-14.4-links-profile-icons https://github.com/vaysenko7882/Nikita-iOS.git "$codegram_update_dir"
git -C "$codegram_update_dir" fetch --depth 1 origin 55cb132946763880dc14561edb95e0a3c654cadf
git -C "$codegram_update_dir" sparse-checkout set server
git -C "$codegram_update_dir" checkout --detach 55cb132946763880dc14561edb95e0a3c654cadf
bash "$codegram_update_dir/server/install.sh" --domain archive.mavasyaa.best --reuse-session
systemctl is-active --quiet nikita-archive
CODEGRAM_UPDATE
```

Если используется другой домен, заменить `archive.mavasyaa.best` своим доменом архива.
Ubuntu 22.04 с Python 3.10 использует совместимую закреплённую версию yt-dlp, Python 3.11+ — более новую.
Не удалять приложение перед обновлением IPA; сохранить bundle ID `personal.nikita.messenger` и прежнюю подпись.

## Проверки

Серверные тесты покрывают архив, миграции/перезапуски, явное включение наблюдения, страницы истории,
неполные списки подарков, скрытых отправителей, события сторис, паузы Telegram, авторизацию, очередь видео
и отказ от локальных сетевых адресов. Проверяются Python 3.10 и 3.11.
UIKit-проверка использует производственные компоненты и записывает анимацию карусели на отдельном симуляторе.
Полная сборка IPA проверяет типы и линковку; упаковка отдельно проверяет наличие восьми альтернативных иконок.
Доступ к живым аккаунтам, доступность конкретного ролика с IP владельца и поведение подписанной IPA на его iPhone
требуют проверки на устройстве; автономные тесты их не подменяют.
