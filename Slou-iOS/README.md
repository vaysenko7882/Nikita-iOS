# слоу для iPhone · версия 2

Внутри приложения — весь «слоу» с твоего сервера: главная с живым логотипом, комнаты, чат, голос, фото и видео в чате, шутки и «Битва за корону». Код у приложения и сайта один, поэтому друг без приложения смотрит и играет с тобой на равных.

Что приложение делает сверх Safari:
- **Заставка.** Буквы «слоу» падают каплями, сплющиваются, слипаются и растворяются прямо в такой же логотип на главной. Каждое приземление отдаётся лёгким толчком в руку.
- **Taptic Engine в играх.** Удар в боксе, взрыв мины, гол, выстрел и каждая нота в «Ритме» ощущаются рукой: щелчок, удар с гулом, «успех», «ошибка». В Safari на айфоне вибрации нет вообще.
- **Битва без лишнего.** Во время игр прячутся строка состояния и полоска «домой». То же — когда плеер развёрнут на весь экран.
- **Звук.** Микрофон разрешается один раз. Звук фильма и голос идут в динамик, а не в ухо. Беззвучный переключатель фильм не глушит. После звонка, Siri или смены наушников звук и видео оживают сами.
- **Экран не гаснет**, пока ты в комнате.
- **«Сохранить»** у фото и видео из чата кладёт их прямо в «Фото».
- **«Поделиться»** приглашением открывает системное окно.
- **Внешние ссылки** (вход в Кинопаб и ссылки из чата) открываются во встроенном Safari поверх приложения.
- Ссылки `slou://r/КОД` открывают комнату. `slou://settings` — сменить адрес сервера.

Адрес сервера уже вшит: `https://slows.best` (ключ `SlouServer` в `Config/Info.plist`). Если поменяешь домен — поменяй его там перед сборкой, или открой в Safari ссылку `slou://settings` уже после установки.

Liquid Glass включается на iOS 26 при сборке в Xcode 26 и новее, на iOS 17–18 вместо него матовое стекло. Минимальная версия — iOS 17.

## Вариант 1: на своём Mac

1. Открой `Slou.xcodeproj` в Xcode 26.
2. Цель Slou → Signing & Capabilities → Team. Подойдёт бесплатный Apple ID (тогда приложение живёт 7 дней, потом его надо поставить заново).
3. Если Xcode скажет, что Bundle ID занят, поменяй `app.slou.watch` на свой, например `app.slou.vasya`.
4. Подключи айфон и нажми ▶︎.

Неподписанный IPA одной командой: `bash scripts/build_ipa.sh`.

## Вариант 2: без Mac, через GitHub

1. Создай приватный репозиторий и загрузи в него содержимое этой папки вместе со скрытой папкой `.github`.
2. Actions → «Собрать IPA» → Run workflow.
3. Через 5–10 минут в разделе Artifacts появится `Slou-ipa`, внутри `Slou.ipa`.
4. Поставь через Sideloadly, AltStore или свой сертификат (Esign, Scarlet, ksign).

Если ставил первую версию — новая встанет поверх, если Bundle ID тот же.

## Если что-то не собирается

- **Ошибка формата проекта.** Нужен Xcode 16 или новее. Запасной путь: `brew install xcodegen && xcodegen` пересоздаст проект из `project.yml`.
- **Ошибки в Swift-файлах.** Пришли текст ошибки (на GitHub он лежит в `build-log` у неудачного запуска) — поправлю.

## Структура

```
Slou/
  SlouApp.swift       запуск, главный экран, заставка поверх страницы
  WebShell.swift      страница сервера и мост к ней: вибрация, звук, фото, «Поделиться»
  SplashView.swift    заставка с падающими буквами-каплями
  LetterShapes.swift  контуры букв логотипа (те же, что на сайте)
  SetupView.swift     адрес сервера и экран «Не открылось»
  AppModel.swift      адрес сервера, ссылки slou://, состояние комнаты и битвы
  Platform.swift      Taptic Engine, аудиосессия, сохранение в «Фото», Safari, «Поделиться»
  Theme.swift         цвета, шрифты, Liquid Glass и запасное стекло
Config/Info.plist     адрес сервера, микрофон, камера, «Фото», фоновый звук, ссылки slou://
.github/workflows/ipa.yml  сборка IPA в облаке
```
