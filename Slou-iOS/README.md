# слоу для iPhone · версия 3

Комнаты, чат, голос и фильмы приходят со страницы твоего сервера. Битва за корону, все десять игр, арена, вызов, финал с короной и 💩 — родной код iOS: свой движок отрисовки на 120 кадров в секунду, мультитач, наклон телефона, Taptic Engine, свои звуки и шрифты внутри приложения.

**Сервер обновлять не нужно.** Приложение само подменяет битву на странице своей: вызов и ответ уходят через ту же комнату, игра идёт по тому же быстрому каналу `/api/live`. Поэтому друг может играть с тобой хоть в приложении, хоть в браузере.

## Что нового

У каждой игры три раунда, второй и третий сложнее. Перед первым раундом — афиша игры.

**Арена.** Счёт, портреты, кто сейчас король, перевес по очкам, живой счёт соперника. «Сдаться» нужно подержать — случайно не нажмёшь. На время битвы экран фиксируется вертикально, прячутся строка состояния и полоска «домой».

**Финал.** Корона по дуге летит на голову победителя (из-за спины проигравшего, если места поменялись), 💩 шлёпается на проигравшего и сплющивает его портрет. Победителю — конфетти и фанфары, проигравшему — грустные ноты.

**Аркада.** Встряхни телефон — откроется тренировка с ботом: любая игра или все десять подряд, без сети. Ещё она есть в настройках и по ссылке `slou://arcade`.

**Плеер.** Плашка с качеством и «во весь экран» над плеером убрана. Чтобы смотреть на весь экран, поверни телефон боком.

**Остальное** осталось: заставка с падающими буквами, микрофон без лишних вопросов, звук в динамик, экран не гаснет в комнате, «Сохранить» кладёт фото в «Фото», системное «Поделиться», внешние ссылки во встроенном Safari.

Звуки (70 эффектов) синтезированы специально для «слоу». Шрифты — под открытой лицензией OFL, тексты лицензий в `Slou/Fonts/licenses`.

Адрес сервера вшит: `https://slows.best` (ключ `SlouServer` в `Config/Info.plist`). Минимальная iOS — 17. Liquid Glass включается на iOS 26 при сборке в Xcode 26.

## Сборка

**На Mac.** Открой `Slou.xcodeproj` в Xcode 26, выбери Team в Signing & Capabilities, подключи айфон, нажми ▶︎. Неподписанный IPA: `bash scripts/build_ipa.sh`.

**Без Mac.** Загрузи папку (вместе со скрытой `.github`) в приватный репозиторий GitHub → Actions → «Собрать IPA» → Run workflow. Через 5–10 минут в Artifacts будет `Slou.ipa`. Ставь через Sideloadly, AltStore или свой сертификат. Встанет поверх прошлой версии, если Bundle ID тот же.

Если сборка упадёт — пришли текст ошибки (на GitHub он в артефакте `build-log`), поправлю.

## Структура

```
Slou/
  SlouApp.swift        запуск, главный экран, поворот → кино на весь экран, встряска → Аркада
  WebShell.swift       страница сервера, сообщения от неё, вызов её функций
  BridgeScript.swift   мост, который встраивается в страницу (сгенерирован из bridge/SlouBridge.js)
  Games/
    GameKit.swift      движок: кадры, касания, жесты, частицы, надписи, тряска, зерно плёнки
    Catalog.swift      список игр, правила, шрифты и афиши
    Box, Race, Mines, Showdown, Samurai, Goal, Range, Arm, Hoop, Beat .swift — сами игры
    Sound.swift        звуки игр
  Duel/
    Arena.swift        ход битвы: связь, отсчёт, раунды, счёт, финал, бот
    DuelCenter.swift   вызов, ответ, сообщения, тренировка
    LiveLink.swift     быстрый канал /api/live
    ArenaView, CeremonyView, DuelLayer, DuelParts .swift — экраны
  Fonts/, Sounds/      шрифты игр и звуки
bridge/SlouBridge.js   исходник моста; после правки: python3 scripts/embed_bridge.py
```
